# 黑盒验收报告：场景纠错、动物避雨与夜间居住

**汇总：10 PASS / 0 FAIL / 0 SKIP / 0 BLOCKED**

验收地址：`http://127.0.0.1:8060/index.html`
验收方式：Chromium + Playwright 黑盒操作；实际点击下雨、夜晚按钮，并通过页面公开 `window.__dbg` API 采集状态。未读取实现源码。完整 API 采样记录见 `evidence-final-20260912-170806.json`。

## GEOM-01 [关键] 餐厅桌子有完整支撑

- **判定**：✅PASS
- **实际现象**：进入美味餐厅后，三张桌子均能看到中央桌腿，桌腿从地面延伸到桌面底部；公开几何状态中三张桌子的桌面底部均为 `1.50`，桌腿顶部均为 `1.55`，有 `0.05` 的轻微穿入，没有悬空间隙。
- **证据**：`shots/GEOM-01-restaurant-tables.png`；`evidence-final-20260912-170806.json` → `baseline.tableSupportInfo`

## PLAY-02 [关键] 室内、室外滑梯与孩子轨迹

- **判定**：✅PASS
- **实际现象**：室内游乐场和室外游乐场均能看到完整黄色滑道，孩子位于滑道高低端范围内，未观察到脱离滑道的空中滑行；公开状态显示两座滑梯朝向分别为 `0.42`、`0.43`，孩子高度与滑道位置对应。
- **证据**：`shots/PLAY-02-indoor-slide.png`、`shots/PLAY-02-outdoor-slide.png`；`evidence-final-20260912-170806.json` → `baseline.slideInfo`

## LAYOUT-03 [关键] 树木不在房屋内部

- **判定**：✅PASS
- **实际现象**：娃娃屋和周边住宅之间的树木均落在草地空隙中，未看到树干穿入房屋；公开空间状态中最近的一棵树与建筑中心距离为 `25.55`，其余均不小于 `29.73`。
- **证据**：`shots/LAYOUT-03-tree-house-clearance.png`；`evidence-final-20260912-170806.json` → `baseline.treeBuildingClearance`

## TRANSPORT-01 [关键] 陆地只保留飞机体验馆

- **判定**：✅PASS
- **实际现象**：可进入的交通体验馆计数为 1，标签仅为“红色飞机体验舱”，类型仅为 `plane`；页面未出现卖船或卖潜水艇式陆地体验馆。
- **证据**：`shots/TRANSPORT-01-plane-only.png`；`evidence-final-20260912-170806.json` → `baseline.transportCount/transportLabels/transportTypes`

## TRANSPORT-02 [关键] 船和潜水艇在河道航行

- **判定**：✅PASS
- **实际现象**：公开状态中有 3 条观光船和 1 艘潜水艇；间隔 3.5 秒的两次采样均显示四者位置持续变化且河道中心偏差约 `0.13～5.09`，仍位于河面宽度内。潜水艇视角中可直接看到黄色潜水艇贴在河面航行。
- **证据**：`shots/TRANSPORT-02-river-submarine.png`；`evidence-final-20260912-170806.json` → `baseline.riverTransportInfo`、`transportLater.riverTransportInfo`

## CHILD-EVAC-01 [关键] 河边孩子安全玩耍并在雨天回家

- **判定**：✅PASS
- **实际现象**：白天 8 名相关孩子均为 `out/play` 状态，离河道中心距离为 `48.93～75.82`，位于安全草坪。点击“下一场雨”后，8 人同时转为 `going`，5、10、15、25 秒采样持续沿回家路线推进；35 秒时全部变为 `home`，45 秒复核仍保持在家，未观察到来回抢位或卡住。
- **证据**：`shots/CHILD-EVAC-01-rain-35s.png`；`evidence-final-20260912-170806.json` → `rainTrajectory`

## ANIMAL-SHELTER-01 [关键] 动物雨天进入共用笼舍

- **判定**：✅PASS
- **实际现象**：下雨后视角中只有一座带顶、带围栏的共用笼舍；10 只兔子、猫和狗共 12 只动物均进入笼舍。公开状态显示 12 个 `inside` 全为 `true`、猫球 `ballVisible=false`、动物雨伞数为 `0`。
- **证据**：`shots/ANIMAL-SHELTER-01-rain.png`；`evidence-final-20260912-170806.json` → `rainFinal.petShelterInfo`

## NIGHT-ALL-01 [关键] 夜间停止活动并睡觉

- **判定**：✅PASS
- **实际现象**：点击“夜晚”并等待 12 秒后，公开状态显示 35 名回家住户全部进入睡眠状态；住宅蒸汽、餐厅工作人员、商店人物、户外孩子、桥上人物和登山者可见数均为 `0`。沙发睡眠位为 9、长椅睡眠位为 0，未出现长椅替代床位。
- **证据**：`shots/NIGHT-ALL-01-night.png`；`evidence-final-20260912-170806.json` → `night.nightInfo`

## FLOOR-OCC-01 [关键] 多层住宅逐层居住

- **判定**：✅PASS
- **实际现象**：17 座住宅的占用层列表与各自楼层数完全一致；所有二层住宅均为 `[1,2]`，所有三层住宅均为 `[1,2,3]`。夜间公开状态显示 18 名上层住户在本层沙发休息，三层住宅视角可见二、三层均有住户，没有全挤在一楼。
- **证据**：`shots/FLOOR-OCC-01-house17-floor3-night.png`；`evidence-final-20260912-170806.json` → `baseline.floorOccupancy`、`night.floorOccupancy`、`night.nightInfo.upperResidentsSleepingOnSofas`

## STABILITY-01 [关键] 页面与控制台稳定

- **判定**：✅PASS
- **实际现象**：入口 HTTP 状态为 200，标题正常，页面存在 1 个 canvas；完成多次视角切换、下雨、45 秒撤离与夜间切换后，控制台错误和页面异常均为 0，WebGL 画面持续正常渲染。
- **证据**：`shots/STABILITY-01-entry.png`；`evidence-final-20260912-170806.json` → `httpStatus/canvasCount/consoleErrors/pageErrors`
